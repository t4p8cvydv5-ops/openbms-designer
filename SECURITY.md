# Security Policy

## Supported versions

Only the latest version on the `main` branch is supported during the early
development phase.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting if it is enabled for the
repository. Otherwise, contact the repository owner privately through their
GitHub profile. Do not disclose a vulnerability in a public issue before a fix
is available.

Do not include customer names, credentials, private network details or real
building point lists in a report.
